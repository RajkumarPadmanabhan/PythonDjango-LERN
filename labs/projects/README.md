| File | Lesson |

Each file runs a self-check when you start it. Django projects in the Projects track are created with `startproject` in their own folders. Follow the lesson rather than copying the task board's models.

```powershell
py -3 labs\projects\guess_the_number.py
```

Programs that call `input()` are for the terminal. The self-check runs first.

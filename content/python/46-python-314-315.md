Django 6.1 supports Python 3.12, 3.13, 3.14, and 3.15. Code in this course uses syntax that works on 3.12 unless a section names a newer version.

## Python 3.14

**Template strings.** `t"Hello {name}"` does not return a `str`. It returns `string.templatelib.Template`, a sequence of literal pieces and `Interpolation` objects. A renderer decides how to escape each value. That is the right building block for HTML and SQL. F-strings still concatenate immediately, which is why an f-string of raw HTML remains unsafe. Django templates remain the tool you should use for pages.

**Deferred annotations.** Annotations are no longer evaluated when the function is defined. They are computed when inspected. Forward references usually do not need quotes, and `from __future__ import annotations` is unnecessary on 3.14+ for that purpose. `annotationlib.get_annotations(fn, format=Format.VALUE)` forces evaluation.

**Other highlights.** Free-threading is officially supported as an opt-in build. Subinterpreters are in the standard library. `compression.zstd` compresses with Zstandard. `except` and `except*` may omit parentheses in the forms the grammar allows; parentheses remain readable. The REPL highlights syntax. `return`, `break`, and `continue` that would leave a `finally` block are syntax errors, because they skipped cleanup in surprising ways.

## Python 3.15

**Lazy imports.** At module level:

```python
lazy import json
lazy from pathlib import Path
```

The name is a proxy until first use. Failures surface at first use, and the traceback includes both places. `lazy` is illegal inside a function, class, or `try`. You cannot lazily import `*` or `__future__`. A global switch exists (`python -X lazy_imports=all`) and a filter API, `sys.set_lazy_imports_filter`. For code that must run on older Python too, a module can set `__lazy_modules__ = ["json"]` and use a normal import; 3.15 treats those imports as lazy.

**frozendict.** `frozendict(a=1)` is an immutable mapping, not a subclass of `dict`. It is hashable when its contents are. Equality ignores order. `isinstance(value, dict)` does not accept it. Test `collections.abc.Mapping` when any mapping will do.

**sentinel.** `MISSING = sentinel("MISSING")` creates a unique truthy object with a useful repr. Compare with `is`. The name is positional-only. `repr=` is keyword-only. Define sentinels once at module level if you want them to pickle.

**UTF-8 by default.** `open(path)` uses UTF-8 even when the Windows locale does not. Pass `encoding="utf-8"` explicitly anyway. `encoding="locale"` recovers the old behavior. `PYTHONUTF8=0` or `-X utf8=0` disables UTF-8 mode.

**Unpacking in comprehensions.** `[*group for group in groups]` flattens one level. `{**d for d in dicts}` merges dicts, with later keys winning.

**Profiling.** `profiling.tracing` is the deterministic profiler (`cProfile` remains as an alias). `profiling.sampling` is the Tachyon sampling profiler, including a way to attach to a running process. The old `profile` module is deprecated.

## How to practice the new syntax

The in-browser runner may be older than 3.15. Use your local `py -3.15` for these examples. If a project must support 3.12, do not ship `lazy`, `frozendict`, t-strings, or comprehension unpacking. The rest of the course stays on syntax Django can run everywhere it supports.

:::quiz
What does a t-string return?
+ A Template that keeps literal text and interpolations separate
- A str, exactly like an f-string
- A bytes object
because: The point of t-strings is to let a renderer escape values before concatenation. F-strings are already concatenated.
:::
